# insurance-risk-analytics


## Project Overview
This project analyzes historical car insurance claims data from AlphaCare Insurance Solutions (ACIS) to identify risk patterns, optimize pricing strategies, and support evidence-based pricing decisions.

## Objectives
- Perform exploratory data analysis
- Analyze loss ratios and profitability
- Identify geographic and demographic risk trends
- Build predictive pricing models

## Technologies Used
- Python
- Pandas
- Seaborn
- Scikit-learn
- Jupyter Notebook
- GitHub Actions
- DVC
